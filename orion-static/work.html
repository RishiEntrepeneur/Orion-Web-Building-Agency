This site

I have no client list to show you, so here is the thing you are standing in, taken apart. Six problems it posed, how each was solved, and every number measured rather than claimed.

06 problems 0 dependencies Measured in Chromium
01 The teardown Problem, then fix

The teardown

01 / 06

Hairlines that vanish

The display face is Bodoni Moda, a didone: thick stems, hairline thins. Reversed out of a near-black ground the thins dropped below one device pixel and disappeared — the hyphen in "E-commerce" went missing and "48h" read as "l8h".

  • AOptical sizing switched off, opsz pinned by hand
  • BThree bands: 26 for display, 15 for headings, 9 for numerals
  • CLower optical sizes carry sturdier hairlines, so the type holds
  • DWord masks widened to 0.26em so descenders are not clipped
  • EThe whole story
02 / 06

One loop, three phases

Nine separate effects were each measuring an element and then styling it, in turn, every frame. Every measurement after the first write forced the browser to lay the whole page out again. That, not the easing curve, is what makes scroll animation judder.

  • AOne requestAnimationFrame loop for the entire site
  • BRead, then think, then write — never interleaved
  • CCallbacks register into the phase they belong in
  • DDamping is frame-rate independent, so 60Hz and 144Hz match
  • EHow it was proved
03 / 06

Software 3D, no WebGL

The exploded view on the home page and the armillary in the hero are real 3D — rotation, perspective divide, depth sorting — drawn on a plain 2D canvas. No WebGL, no Three.js, no shader compile, and nothing to download.

  • ARotate about Y, then X; project with f = dolly / (dolly + z)
  • BPrimitives depth-sorted every frame so occlusion reads correctly
  • CA six-keyframe camera sampled by scroll position, not by a clock
  • DExactly one layer lit at a time, so one thing is legible at once
  • ECollapses to a single static frame under reduced motion
04 / 06

One origin, nothing else

Nothing on these pages is fetched from anybody else's server. No font CDN, no analytics, no tag manager, no embedded player — seven to nine requests a page, every one of them from this domain. A third party cannot slow this site down, break it, or learn that you visited, because there is no third party.

  • AThree variable font families, self-hosted, latin subsets
  • BOne stylesheet, one script, both hand-written
  • CSound is synthesised at runtime, so there are no audio files
  • DEvery graphic is generated by code — no image payload
  • EZero npm dependencies in the browser and zero at build time
05 / 06

Contrast, computed

Seven accent colours on a violet-black ground is exactly the situation where contrast quietly fails. So no pairing on this site was approved by eye: each one had its ratio calculated, and the ones that missed were changed until they passed.

  • AAll seven zone colours clear 4.5:1 as body text
  • BInteractive borders use a dedicated token at 3:1 (WCAG 1.4.11)
  • CThe drawer traps focus; Escape closes it and restores focus
  • DClosed panels are inert, so nothing hidden is tabbable
  • EUnder reduced motion nothing is ever left at opacity: 0
06 / 06

A budget that refuses

Every claim on this page is a number somebody could check, so each one is produced by a script that drives a real browser and fails if the figure moves the wrong way. A target nobody is allowed to miss is a different object to one everybody agrees with.

  • ALargest contentful paint held under 0.9s on every page
  • BContrast ratios recomputed from the rendered colours
  • CHorizontal overflow checked at seven viewport widths
  • DEvery internal link crawled, so nothing clickable is inert
  • EWhy it has to fail the build
HTML5· CSS custom properties· ES2020· Canvas 2D· Web Audio· IntersectionObserver· Variable fonts· Node build script· Playwright checks· No dependencies·

Numbers you could check

Dependencies

Forced layouts per frame

Self-hosted families

Widths tested
